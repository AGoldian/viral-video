# Сервис автоматической генерации трейлеров

Наш сервис автоматически превращает ваши видео в серию захватывающих трейлеров! Мы генерируем уникальные короткие клипы с самыми интригующими моментами, чтобы вызвать у зрителей желание посмотреть полную версию. С автоматической генерацией описаний и хештегов, а также встроенным редактором эмодзи и текста, вы получаете мощный инструмент для создания вирусного контента и привлечения внимания к вашему основному материалу.

# Описание:
Генераторы кандидатов:
`r2_candidates.py` - генератор кандидатов на основе R2-Tuning (аудио + видео)
`splash_audio_candidates.py` - генератор кандидатов на основе эвристик звука (средняя громоксть и частота изменений амлитуд)
`llama_text_candidates.py` - генератор кандидатов на основе Llama

`video_agg.py` - Этот скрипт обрабатывает видео: объединяет клипы по временным меткам, транскрибирует аудио с помощью Whisper, добавляет субтитры, и сохраняет финальное видео.
`utils.py` - вспомогательные функции

`main-cli.py` - консольный интерфейс для генерации трейлеров со всеми кандидато-генераторами
`main-audio-cli.py` - консольный интерфейс для генерации трейлеров с звуковыми кандидато-генераторами
`main-audio-llama-cli.py` - консольный интерфейс для генерации трейлеров с звуковыми и LLM кандидато-генераторами
`main.py` - пример вызова для всех кандидато-генераторов

`rest/pythonProject3` - бэк часть для похода во фронт

`notebooks` - ноутбуки с экспериментами 

`client` - фронтенд

`settigs` - конфиги


## Реализованный функционал
- ⏏️ Загрузка видео на сервер с клиента
- 🔀 Загрузка видео на сервер по ссылке RuTube
- 🔁 Поллинг списка смонтированных клипов с сервера
- 🎦 Просмотр смонтированных клипов
- 📲 Редактирование клипов и сохранение на мобильном устройстве

## Ключевые особенности
- ⚒ **МЛ-анализ**: Используем передовые модели машинного обучения, такие как Whisper для транскрибации аудио с последующим анализом LLM, R2-Tuning для выделения "вирусных" моментов и AudioAnalyzer для выделения интересных звуковых моментов.
- 🔑 **Кроссплатформенность**: Сервис создан на Flutter и работает как в вебе, так и на мобильных устройствах.
- ⚙️ **Автоматическое создание контента**: Генерация описаний и хештегов, а также возможность редактировать эмодзи и текст в видео.
- 🧠 **Эффективная обработка**: Модель LLama 3.1 (до 8B параметров) обеспечивает быструю обработку и агрегацию информации.

## Технические особенности

1. **Whisper** — для транскрибации аудио и выявления "вирусных" моментов.
2. **R2-Tuning** — для анализа видеоряда и выбора интригующих моментов.
3. **LLama 3.1** — для быстрой обработки данных и их агрегации.

## Как запустить проект

### Требования

- **Python 3.10+**
- **Docker** (необходим для запуска сервиса)
- **Flutter SDK**
- **Node.js** (для разработки фронтенда, если потребуется)

### Установка

- [Скачать веса для Whisper (medium.pt)](https://openaipublic.azureedge.net/main/whisper/models/345ae4da62f9b3d59415adc60127b97c714f32e89e936602e85993674d08dcb1/medium.pt)

- [Скачать веса для LLama 3.1 8B-instruct](https://www.kaggle.com/models/metaresearch/llama-3.1/transformers/8b-instruct) или [Llama 3.2 3B](https://www.kaggle.com/models/metaresearch/llama-3.2/transformers/3b-instruct) (лучше 8B-instruct, т.к 3B галлюционирует)

1. **Клонирование репозитория и установка**:

   ```bash
   git clone https://github.com/AGoldian/viral-video.git
   cd viral-video
   ```

   ```bash
   pip install -r requirements.txt
   python main-cli.py --base_path './rest/pythonProject3/' --fname '4cb8085a4154b91c5e6288c33b70949c.mp4'
   ```

   ```bash
   pip install -r requirements.txt
   python main-audio-cli.py --base_path './rest/pythonProject3/' --fname '4cb8085a4154b91c5e6288c33b70949c.mp4'
   ```
   

2. **Запуск сервиса с использованием Docker:**


Убедитесь, что Docker установлен, и выполните следующие команды:

```bash

docker build -t viral-video .
docker run -p 8000:8000 viral-video
```
Это создаст и запустит контейнер, готовый к использованию.

**Доступ к веб-интерфейсу:**

Откройте браузер и перейдите по адресу http://localhost:8000, чтобы начать использовать сервис.

### Как запустить Flutter фронтенд
- Установить Flutter следуя официальной документации -- https://docs.flutter.dev/get-started/install
- Перейти в папку клиента и загрузить зависимости
```bash
cd client
flutter pub get
```
- Запустить с помощью команды flutter run в любом браузере:
```bash
flutter run -d chrome
```
- Вы великолепны!

Или собрать apk-файл для последующей установки на Android-девайс:
```bash
flutter build apk
```

Для деплоя на iOS (требуется MacOS):
```bash
flutter build ios
```

#### Особенности конфигурации клиента
- Для запуска веб-сервиса фронта внутри docker-образа подставить в ApiImpl _base localhost. В таком случае весь сетевой трафик по REST api будет происходить только между экземплярами сервисов внутри контейнера и архитектура для внешней среды будет представлять из себя монолит.
- Для запуска android/ios/аврора приложения указывать внешний ip-адрес развернутого бэкенд сервиса. Общение между фронтом и бэкендом в таком случае представляет из себя клиент-серверную архитектуру.
