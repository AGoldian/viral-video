# Сервис автоматической генерации трейлеров

Наш сервис автоматически превращает ваши видео в серию захватывающих трейлеров! Мы генерируем уникальные короткие клипы с самыми интригующими моментами, чтобы вызвать у зрителей желание посмотреть полную версию. С автоматической генерацией описаний и хештегов, а также встроенным редактором эмодзи и текста, вы получаете мощный инструмент для создания вирусного контента и привлечения внимания к вашему основному материалу.

Описание:

Генераторы кандидатов:
`r2_candidates.py` - генератор кандидатов на основе R2-Tuning (аудио + видео)

## Ключевые особенности

- **МЛ-анализ**: Используем передовые модели машинного обучения, такие как Whisper для транскрибации аудио и R2-Tuning для выделения "вирусных" моментов.
- **Кроссплатформенность**: Сервис создан на Flutter и работает как в вебе, так и на мобильных устройствах.
- **Автоматическое создание контента**: Генерация описаний и хештегов, а также возможность редактировать эмодзи и текст в видео.
- **Эффективная обработка**: Модель Distillate-LLM (до 3B параметров) обеспечивает быструю обработку и агрегацию информации.

## Технические особенности

1. **Whisper** — для транскрибации аудио и выявления "вирусных" моментов.
2. **R2-Tuning** — для анализа видеоряда и выбора интригующих моментов.
3. **Distillate-LLM** — для быстрой обработки данных и их агрегации.

## Как запустить проект

### Требования

- **Python 3.10+**
- **Docker** (необходим для запуска сервиса)
- **Flutter SDK**
- **Node.js** (для разработки фронтенда, если потребуется)

### Установка

1. **Клонирование репозитория**:

   ```bash
   git clone https://github.com/your-username/auto-trailer-service.git
   cd auto-trailer-service
    ```

2. **Запуск сервиса с использованием Docker:**


Убедитесь, что Docker установлен, и выполните следующие команды:

```bash

docker build -t auto-trailer-service .
docker run -p 8000:8000 auto-trailer-service
```
Это создаст и запустит контейнер, готовый к использованию.

Доступ к веб-интерфейсу:

Откройте браузер и перейдите по адресу http://localhost:8000, чтобы начать использовать сервис.

**Flutter фронтенд**
Установка Flutter:

Следуйте официальной инструкции по установке Flutter.

Запуск веб-приложения на Flutter:

Перейдите в папку с фронтендом:

```bash
cd flutter_web
flutter run -d chrome  # Запуск приложения в Chrome
```
Деплой на мобильные устройства:

Для деплоя на Android:

```bash
flutter build apk  # Сборка APK для Android
```

Для деплоя на iOS (требуется MacOS):
```bash
flutter build ios
```
